# She Can Foundation

A small static website for the She Can Foundation, designed to showcase a nonprofit-style landing page focused on women's education, leadership, and career support.

## Overview

This project contains a simple student-made landing page with:
- an about section
- programs and impact stats
- testimonials
- project showcase cards
- a volunteer/contact form with client-side validation and a toast notification

## Files

- `index.html` — the website markup
- `style.css` — the site styling and responsive layout
- `script.js` — interactive behavior for the join button, contact form submission, and toast messages

## Features

- Responsive layout using CSS flexbox and cards
- Smooth scrolling to the contact section
- Simple contact form handling with built-in validation
- Toast notifications for form submission feedback

## Usage

1. Open `index.html` in a web browser.
2. Use the navigation links to explore the page.
3. Click **Join Our Mission** to scroll to the contact form.
4. Submit the form to see client-side feedback.

## Notes

- The project is static and does not require a build step.
- If a form endpoint is configured via `window.FORM_ENDPOINT`, the form will post JSON to that endpoint.
